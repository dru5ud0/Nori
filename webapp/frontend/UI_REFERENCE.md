# UI Reference

The webapp uses the open-source NeoBrutalism/RetroUI component language from
`neobrutalism/neobrutalism` (MIT): black 2px borders, small corner radii, hard
offset shadows, flat high-contrast surfaces, and mechanical button movement.

Reference registry components:

- `https://neobrutalism.com/r/base/button.json`
- `https://neobrutalism.com/r/base/card.json`
- `https://neobrutalism.com/r/base/input.json`

The paid BrutAdmin template was used only as a layout reference and was not
copied. TsentaClone retains its own React/Vite application architecture and
job-automation workflows.
